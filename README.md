 Jeu de Devinettes - Java

Ce projet est un jeu simple développé en Java dans le cadre d’un exercice d’apprentissage.

 Objectif
Deviner un nombre aléatoire compris entre 1 et 100 en un maximum de 10 essais.

Fonctionnement
- Un nombre secret est généré aléatoirement.
- L’utilisateur propose un nombre.
- Le programme indique si le nombre est trop grand ou trop petit.
- Le joueur gagne s’il trouve le bon nombre.
- Le joueur perd après 10 essais.

Concepts utilisés
- Variables
- Boucles (while)
- Conditions (if / else)
- Entrée utilisateur (Scanner)
- Nombre aléatoire (Random)

Exécution
Compiler et lancer le fichier `Main.java` dans IntelliJ ou un autre IDE Java.

Auteur
Projet réalisé dans un but d’apprentissage Java.
